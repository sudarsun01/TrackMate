Attendance management is one of the most crucial administrative tasks in educational institutions, directly impacting student safety, discipline, and accountability. In recent years, the need for a reliable and automated attendance system has gained significant attention, especially in the context of school transportation. Traditional attendance systems such as manual roll calls, RFID cards, and barcode-based methods often suffer from inefficiency, data inaccuracy, and the risk of misuse or proxy attendance. These limitations not only affect record accuracy but also compromise the safety of students, particularly during school bus transportation. To overcome these challenges, this project proposes a Fingerprint Sensor-Based Attendance System for School Bus Students, integrating biometric identification with IoT-based data management for enhanced security and reliability.
Biometric authentication, particularly fingerprint recognition, has emerged as one of the most secure and efficient methods for personal identification due to its uniqueness and non-replicable nature. Unlike RFID cards or ID tags, which can be lost or swapped, a fingerprint provides a tamper-proof and user-specific verification method. By leveraging this technology, the proposed system ensures that only authorized students can mark their attendance, thereby eliminating the possibility of impersonation or proxy attendance. The use of a fingerprint sensor module interfaced with an ESP32 microcontroller enables real-time student verification as they board or leave the school bus.
The ESP32 serves as the central processing and communication unit of the system. It captures the fingerprint data, compares it with the pre-stored database, and transmits the verified attendance record to a SQL Server database via a wireless network. This seamless integration of hardware and software allows for automated data logging and real-time synchronization, reducing manual effort and human error. The web-based monitoring platform, developed using HTML, CSS, and JavaScript, provides a user-friendly interface for school administrators and parents to track student attendance and bus activity in real time. The platform displays information such as the student’s name, bus number, timestamp, and verification status.
An additional safety mechanism is incorporated to ensure that students board the correct bus. If a student attempts to enter a bus not assigned to them, the system immediately triggers an alert message, notifying the driver and preventing unauthorized boarding. To support this functionality, the bus driver’s smartphone can be placed on a designed mobile stand, allowing them to access the system dashboard while maintaining driving safety.
The proposed system not only enhances operational efficiency but also strengthens the safety and accountability measures of student transportation. It is cost-effective, scalable, and suitable for integration with existing school management systems. Furthermore, the use of IoT and biometric technologies aligns with modern trends in smart education and digital transformation. By minimizing human intervention and providing real-time visibility, this project offers a sustainable and technologically advanced approach to student attendance tracking during transportation, ensuring peace of mind for both parents and school authorities.
